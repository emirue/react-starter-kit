# CLI options

```text
create-produx-app [options] [directory]
```

`[directory]` is the project directory for standalone apps and new monorepos (the last path segment becomes the package name and must be a valid npm name), or the app name for `--mode existing-workspace`.

| Option                             | Values                                                 | Default                                                                            | Notes                                                                                                                                                                                                                                                |
| ---------------------------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--mode`                           | `standalone`, `monorepo`, `existing-workspace`         | `standalone` (interactive: asks; suggests existing-workspace when one is detected) |                                                                                                                                                                                                                                                      |
| `--preset`                         | `minimal`, `standard`, `admin`, `enterprise`, `custom` | `standard`                                                                         |                                                                                                                                                                                                                                                      |
| `--package-manager`                | `pnpm`, `npm`, `yarn`, `bun`                           | the one that launched the CLI, else `pnpm`                                         | Existing workspace: always the detected one; a different value is an error. Monorepo modes: pnpm only.                                                                                                                                               |
| `--features`                       | comma list                                             | preset's list                                                                      | `a,b` replaces the list; `+a,-b` adjusts it; mixing both forms is an error.                                                                                                                                                                          |
| `--ui`                             | `base`, `radix`                                        | `base`                                                                             | Requires `shadcn`.                                                                                                                                                                                                                                   |
| `--router`                         | `react-router`, `tanstack-router`, `none`              | preset                                                                             | Cannot be combined with router ids in `--features`.                                                                                                                                                                                                  |
| `--workspace-root`                 | path                                                   | detected from the current directory                                                | Must be the workspace root itself.                                                                                                                                                                                                                   |
| `--app-name`                       | npm name                                               | `web` (monorepo) / `[directory]` (existing)                                        | Must not clash with an existing workspace package.                                                                                                                                                                                                   |
| `--app-dir`                        | relative path                                          | `apps/<app-name>`                                                                  | Letters, digits, `.`, `_`, `-` and `/` only; no `..`, absolute paths, drive letters, spaces or quotes (the value is written into YAML, Dockerfiles and CI files). Must stay inside the workspace.                                                    |
| `--turbo`, `--no-turbo`            |                                                        | on                                                                                 | New monorepo only.                                                                                                                                                                                                                                   |
| `--config`                         | file                                                   |                                                                                    | Loads `produx.config.json`.                                                                                                                                                                                                                          |
| `--save-config`                    | optional file                                          | `produx.config.json` in the project                                                | An existing file is never overwritten.                                                                                                                                                                                                               |
| `--examples`, `--no-examples`      |                                                        | examples on                                                                        |                                                                                                                                                                                                                                                      |
| `-y`, `--yes`                      |                                                        | off                                                                                | Non-interactive; never prompts.                                                                                                                                                                                                                      |
| `--no-install`                     |                                                        | install                                                                            | Validation is skipped too; the result is reported as not verified.                                                                                                                                                                                   |
| `--no-git`                         |                                                        | git init                                                                           | git init is skipped automatically inside an existing repository.                                                                                                                                                                                     |
| `--no-verify`                      |                                                        | verify                                                                             | Skips type check, lint, tests and build.                                                                                                                                                                                                             |
| `--dry-run`                        |                                                        | off                                                                                | Prints the plan and file list; writes nothing.                                                                                                                                                                                                       |
| `--allow-workspace-changes`        |                                                        | off                                                                                | Existing workspace: approves the listed root-file edits and the install, which runs workspace code (root lifecycle scripts, `.pnpmfile.cjs`, packages' install scripts). Without it, `--yes` stops before writing; `--no-install` needs no approval. |
| `-v`, `--version` / `-h`, `--help` |                                                        |                                                                                    |                                                                                                                                                                                                                                                      |

## Rejected combinations

- `--mode standalone` with `--app-dir`, `--app-name`, `--workspace-root`, `--turbo` or `--no-turbo`.
- `--mode existing-workspace` with `--turbo` / `--no-turbo` (Turborepo is detected).
- `--mode monorepo` with `--workspace-root`.
- `--dry-run` with `--save-config`.
- `--allow-workspace-changes` with a mode other than `existing-workspace`.
- `--router` together with router ids in `--features`; `--ui` without `shadcn`.
- Features outside their supported modes or package managers.
- Unknown options and invalid values (exit code 1, nothing written).

## Exit codes

| Code | Meaning                                                                   |
| ---- | ------------------------------------------------------------------------- |
| 0    | Created (and validated unless steps were skipped), help, version, dry run |
| 1    | Invalid input, refused change, or a failed step                           |
| 130  | Cancelled by the user (Ctrl+C or declining the confirmation)              |
