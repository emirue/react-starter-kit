# Design tokens

All tokens live in `src/index.css` (`:root` for light, `.dark` for dark) and are exposed to Tailwind as semantic classes.
Use the classes below in components; do not use raw palette classes (`bg-gray-500`) or hex colors.
Switch the toolbar theme to see the dark values.

## Typography

| Use | Classes |
| --- | --- |
| Page title (via `PageHeader`) | `text-2xl font-semibold tracking-tight` |
| Section title | `text-lg font-semibold` |
| Body | `text-sm` or `text-base` |
| Secondary text | `text-sm text-muted-foreground` |

## Spacing and radius

- Spacing follows Tailwind's 4 px scale. Pages use `p-4 md:p-6`; stacks use `gap-4` or `gap-6`.
- Radius comes from `--radius`: `rounded-sm`, `rounded-md`, `rounded-lg` (= `--radius`), `rounded-xl`.

## Breakpoints

Mobile first: `sm` 640 px, `md` 768 px, `lg` 1024 px, `xl` 1280 px. Pages must not scroll horizontally at 375 px; wide tables scroll inside their own container.
