## Architecture and directories

<!-- @if router -->
- `src/main.tsx` mounts the app; `src/App.tsx` composes providers and the router.
<!-- @else -->
- `src/main.tsx` mounts the app; `src/App.tsx` composes providers.
<!-- @endif -->
<!-- @if providers -->
- `src/app/providers.tsx` holds every app-wide provider. Add new providers there, once.
<!-- @endif -->
<!-- @if react-router -->
- `src/app/router.tsx` defines routes (React Router data mode). Pages are lazy-loaded with `lazy`.
<!-- @endif -->
<!-- @if tanstack-router -->
- `src/routes/` holds file-based routes. `src/routeTree.gen.ts` is generated by the Vite plugin: never edit it by hand.
<!-- @endif -->
- `src/pages/` holds route-level components; `src/layouts/` holds layouts.
- `src/features/<feature>/` holds feature modules with `api/`, `components/`, `hooks/`, `schemas/`, `types/` as needed. Features must not import from each other's internals.
- `src/components/` holds shared components.
<!-- @if shadcn -->
- `src/components/ui/` holds shadcn/ui components. Add more with `{{pmDlx}} shadcn@latest add <name>`.
<!-- @endif -->
- `src/lib/` holds framework-free helpers.
<!-- @if api-client -->
- `src/lib/api-client.ts` is the API client and `src/lib/api-error.ts` defines `ApiError`.
<!-- @endif -->
- `src/config/env.ts` is the only place that reads `import.meta.env`.
- Import from `src` with the `@/` alias.

## Conventions

- File names: `kebab-case.ts(x)`. Components: `PascalCase`. Hooks: `useSomething`.
- TypeScript strict mode is on. Do not use `any`, `@ts-ignore` or blanket `eslint-disable` to silence errors; fix the cause.
- Keep components small and accessible: semantic HTML, labels for inputs, visible focus, keyboard support.
<!-- @if tailwind -->
- Style with Tailwind CSS utilities and the theme tokens in `src/index.css` (e.g. `bg-background`, `text-muted-foreground`).
<!-- @endif -->

## State management rules

<!-- @if tanstack-query -->
- Server state belongs to TanStack Query. Build keys with a key factory (see `src/features/*/api/*-queries.ts`) and invalidate after mutations.
<!-- @if zustand -->
- Do not copy server data into Zustand or React state.
<!-- @else -->
- Do not copy server data into React state.
<!-- @endif -->
<!-- @endif -->
<!-- @if zustand -->
- Zustand is for client state shared across components. Read with selectors. Persist only non-sensitive preferences.
<!-- @endif -->
<!-- @if react-hook-form -->
- Form state belongs to React Hook Form, not to global stores.
<!-- @endif -->
- Local UI state stays in components.

<!-- @if api-client -->
## API integration rules

- Call the backend only through `src/lib/api-client.ts`. It rejects with `ApiError` (`kind`, `status`, `details`).
- Pass the `signal` TanStack Query provides so requests are cancelled.
- The base URL comes from `VITE_API_BASE_URL`. Do not hard-code hosts.
- Authentication: plug headers in with `setAuthHeadersProvider`. Do not invent token refresh or retry logic without the backend contract.
<!-- @if orval -->
- Regenerate the typed client with `{{pmRun}} api:generate` after changing `openapi/openapi.yaml`. Never edit `src/api/generated` by hand.
<!-- @endif -->

<!-- @endif -->
## Security requirements

- Every `VITE_*` variable is public. Never put secrets, tokens or private keys in the frontend or in `.env*` files that are committed.
- Do not store tokens, passwords or personal data in `localStorage`.
- Do not render untrusted HTML (`dangerouslySetInnerHTML`) without sanitising it.
