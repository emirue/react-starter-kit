## Environment variables

Copy `.env.example` to `.env.local` and adjust it. Vite only exposes variables
prefixed with `VITE_`, and **every `VITE_` variable is embedded in the browser
bundle**, so never put secrets in them. Values are read at build time; changing
them requires a rebuild.

## Project structure

The app follows Feature-Sliced Design: each layer imports only the layers below it, and other slices only through their `index.ts`.
<!-- @if eslint -->
`{{pmRun}} lint` checks this (`eslint-plugin-boundaries` in `eslint.config.js`).
<!-- @endif -->
<!-- @if agents-md -->
The full rules are in `AGENTS.md` ("Architecture and directories").
<!-- @endif -->
<!-- @if claude-md && !agents-md -->
The full rules are in `CLAUDE.md` ("Architecture and directories").
<!-- @endif -->

```text
src/
  main.tsx      entry point
  index.css     global styles and design tokens
  app/          composition: app.tsx, providers, router, layouts
<!-- @if tanstack-router -->
  routes/       file-based routes (thin; routeTree.gen.ts is generated)
<!-- @endif -->
  pages/        one slice per screen: ui/, api/, model/, index.ts
<!-- @if theme -->
  features/     user actions used in several places (switch-theme)
<!-- @endif -->
  shared/       domain-free code: ui/ (design system), api/, lib/, config/
<!-- @if msw -->
  mocks/        MSW handlers for development and tests
<!-- @endif -->
<!-- @if vitest -->
  test/         test setup and helpers
<!-- @endif -->
```

## Storybook

`{{pmRun}} storybook` opens the component workshop. Stories live next to their components (`src/shared/ui/*.stories.tsx`), and `src/shared/ui/design-tokens.mdx` documents colors, typography, spacing and breakpoints. Use the toolbar to switch between light and dark.
`{{pmRun}} test:storybook` needs Chromium for Playwright once: `{{pmExec}} playwright install chromium`.
